# Sonus

Player musicale per Windows stile Spotify: playlist, ricerca e download da YouTube, import da Spotify, testi sincronizzati, video di sfondo, equalizzatore, loop A-B, taglio audio.

## ⬇️ Scarica

**[Scarica Sonus per Windows](https://github.com/DaRealDante/Sonus/releases/latest/download/Sonus_Setup.exe)**

1. Apri il file scaricato e segui l'installazione (non servono permessi di amministratore)
2. Se Windows dice "PC protetto": *Ulteriori informazioni → Esegui comunque* (l'app non è firmata)

Gli aggiornamenti arrivano da soli: quando esce una nuova versione l'app ti chiede "Aggiorna ora".

[Tutte le versioni](https://github.com/DaRealDante/Sonus/releases)
